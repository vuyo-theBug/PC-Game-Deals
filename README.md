# PC-Game-Deals
ABOUT THE PROJECT
PC Game Deals is a web application for finding pc games,especially those on discount,compare prices and discover good deals. It includes sample game data as well as live deals retrieved from the CheapShark API.

FEATURES
Display PC games and their prices.
Identify games currently on sale.
Calculate discount percentages.
Search for games by title.
Retrieve live deals using the CheapShark API.

TECH USED
HTML
CSS
JavaScript
Vite
CheapShark API
StackBlitz

HOW TO RUN
Open the project in StackBlitz or download it.
Open the project folder in your terminal.
Install dependencies : npm install
Start the application : npm run dev
